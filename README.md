# 🛡️ Cyber Trainer

**Cyber Trainer** --- учебный терминальный тренажёр на Python для
начинающих специалистов по кибербезопасности.

Проект помогает изучать основы **Linux, сетей и SOC**, а затем
закреплять знания через тесты и практические сценарии расследования.

## 🎯 Цель проекта

Главная идея Cyber Trainer:

> **Изучил → Проверил знания → Применил на практике**

Программа построена так, чтобы пользователь не просто запоминал команды
и термины, а учился рассуждать как начинающий специалист SOC.

### 🎯 Распознавание атак

После изучения атак пользователь получает описание ситуации и должен
определить, какая атака происходит.

Это помогает тренировать навык:

``` text
СОБЫТИЕ
   ↓
ПРИЗНАКИ
   ↓
АРТЕФАКТЫ
   ↓
ГИПОТЕЗА
   ↓
ПРОВЕРКА
```

### 🧪 Безопасная практика Linux

Тренажёр позволяет изучать назначение полезных диагностических команд
Linux:

``` bash
whoami
ip addr
ip route
ss -tulpn
ps aux
systemctl --type=service --state=running
```

Команды используются для обучения анализу системы:

-   кто сейчас работает;
-   какие интерфейсы настроены;
-   какие маршруты существуют;
-   какие порты слушаются;
-   какие процессы запущены;
-   какие службы работают.

### 🛡️ Стажёр SOC

Симулируются ситуации, похожие на реальные задачи начинающего
SOC-аналитика.

Например:

-   подозрительный процесс;
-   необычная сетевая активность;
-   подозрительный вход;
-   неизвестный сервис;
-   возможный майнер;
-   признаки компрометации.

Задача пользователя --- не сразу делать вывод, а сначала собрать факты.

### 🎯 Свободное расследование

В этом режиме пользователь самостоятельно выбирает направление
расследования.

Главный принцип:

> Не угадывать причину инцидента, а подтверждать гипотезу фактами.

Во время расследования тренируется последовательность:

``` text
Triage → Сбор артефактов → Анализ → Гипотеза → Проверка → Вывод
```

## 💻 Установка и запуск

### Требования

-   Python 3
-   Linux/macOS или другая система с поддержкой Python `curses`

На Ubuntu Python обычно уже установлен.

Проверить:

``` bash
python3 --version
```

### Запуск

Скачайте или клонируйте проект:

``` bash
git clone https://github.com/YOUR_USERNAME/cyber-trainer.git
cd cyber-trainer
```

Запустите:

``` bash
python3 cyber_trainer.py
```

## 🔐 Безопасность

Cyber Trainer создавался как **учебный и безопасный тренажёр**.

Программа не предназначена для:

-   взлома чужих систем;
-   обхода защиты;
-   эксплуатации реальных уязвимостей;
-   проведения DDoS-атак;
-   кражи данных.

Практические сценарии используются для обучения анализу инцидентов и
защитной работе.

## 🧠 Чему учит проект

Проект помогает сформировать базовое мышление начинающего SOC-аналитика:

### Вместо:

> «Наверное, это вирус».

### Учимся думать:

> «Какой процесс запущен?»

> «Кто его запустил?»

> «Когда он появился?»

> «С каким адресом он устанавливает соединение?»

> «Есть ли соответствующие записи в логах?»

> «Какие ещё артефакты подтверждают гипотезу?»

Это один из основных навыков, который нужен при расследовании
инцидентов.
